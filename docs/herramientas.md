# Herramientas de código abierto consideradas

| Herramienta | Uso | Decisión |
|---|---|---|
| Navidrome | Servidor de música ligero, API Subsonic | **Elegida** |
| Jellyfin | Servidor multimedia (video y música) | Alternativa, más pesada |
| Funkwhale | Servidor de música con comunidad federada | Alternativa |
| beets | Etiquetado y organización automática de la biblioteca | Recomendada como complemento |
| MPD / mopidy | Reproductores por servidor | No necesarios |
| Tailscale | Acceso remoto privado | **Elegida** |

Fuentes gratuitas y legales: Jamendo (Creative Commons), Internet Archive, Free Music Archive y radios por internet.
No se usan Spotify, YouTube Music ni descargas de servicios comerciales.
